# Soporte

Para diagnosticar un problema, incluye servicio, branch/SHA, ambiente, ruta
afectada, timestamp, código HTTP, correlation/processing ID y pasos para
reproducirlo. Redacta secretos y datos personales.

Consulta primero los runbooks en [`docs/operations/`](docs/operations/README.md)
y el changelog del componente. Los mocks locales no son canales de soporte de
proveedores externos.
