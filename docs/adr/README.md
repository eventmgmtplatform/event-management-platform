# Architecture Decision Records

Las decisiones se conservan junto al dominio que las implementa para mantener
el contexto. Este índice centraliza su localización.

| Dominio | Decisiones |
|---|---|
| Event Processor | [decisions-adr.md](../event-processor/decisions-adr.md) |
| Event State Service | [decisions-adr.md](../event-state-service/decisions-adr.md) |
| CACF | [decisions-adr.md](../cacf/decisions-adr.md) |
| Dashboards | [architecture.md](../dashboards/architecture.md) |
| Git y publicación | [governance.md](../git/governance.md) |

Las nuevas decisiones deben incluir contexto, decisión, alternativas,
consecuencias, compatibilidad y plan de reversión. No se debe reutilizar un ADR
de otro dominio para justificar un contrato diferente.
